# Nin Kanong — Ronin GitHub Profile

A crimson-and-gold samurai theme built around your supplied sunset ronin image, with matching animated README assets.

## Install

1. Download and extract `nin-kanong-ronin-profile.zip`.
2. Create a **public** GitHub repository named exactly `Nin-Kanong` (it must match your GitHub username).
3. Upload `README.md` to the repository root and upload the full `assets` folder beside it.
4. Commit the files and open your GitHub profile to view the README.
5. Set `assets/avatar.png` as your actual GitHub profile picture from GitHub profile settings.

## Included

- `assets/avatar.png` — static avatar based on your supplied image
- `assets/avatar-animated.gif` — pulsing ring and drifting ember animation
- `assets/banner.png` — static name banner
- `assets/banner-animated.gif` — animated banner with a scan glow and drifting embers
- `assets/ember-divider.gif` — animated divider
- `README.md` — profile introduction and About Me
- `profile-preview.png` — static preview

## Notes

- GIF animations work inside README content, but GitHub may show an animated profile picture as static; use the PNG for your account avatar and the GIF inside the README.
- The typing animation uses the external Readme Typing SVG service, and the badges load from Shields.io, so those require an internet connection.
- Update the README wording and repository links as your goals and projects change. No follower counts, contribution counts, or other stats are fabricated.
