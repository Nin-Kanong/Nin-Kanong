## `> whoami` — About Me

Hello, I’m **Nin Kanong**, a Network Engineering and Security student at **Norton University** with a strong interest in cybersecurity, network infrastructure, and practical defensive security.

I enjoy understanding how systems communicate, investigating activity in logs, learning how attacks work, and applying that knowledge to improve detection and protection. I use this GitHub to document my learning, publish lab notes, and build projects that turn theory into practice.

```text
┌─[ nin-kanong@github ]─────────────────────────────────────┐
│  ROLE      : Network Engineering & Cybersecurity Student  │
│  INTEREST  : SOC • Detection • Networking • DFIR basics    │
│  BUILDING  : Phish-Hunter & security lab projects          │
│  PRINCIPLE : Learn carefully. Practice ethically. Share.   │
└────────────────────────────────────────────────────────────┘
```

### Current focus

- **Security operations:** log analysis, alert triage, incident-response fundamentals, and detection concepts.
- **Networking:** TCP/IP, DNS, HTTP/HTTPS, routing, switching, and packet analysis with Wireshark.
- **Security tools:** Nmap, Burp Suite, Nessus/OpenVAS, Splunk and Elastic Stack fundamentals.
- **Practical work:** lab write-ups, small automation scripts, and the [Phish-Hunter](https://github.com/Nin-Kanong/Phish-Hunter) project.
